# ELEC2645 Unit 1.1 C Programming Activities

This repository contains the six Unit 1.1 programming activities in one folder. You do not need to move between folders in the terminal.

## Activities

Work through the activities in order. Open the Markdown file, follow its instructions, and edit the corresponding C file.

1. Activity 1: Hello World
2. Activity 2: Data Types
3. Activity 3: Loops
4. Activity 4: If...Else
5. Activity 5: While Loops
6. Activity 6: Debug Practice

## Reference guide

The [ELEC2645 reference guide](https://eee-elec2645.github.io/) contains explanations and examples covering most of the C programming concepts needed for these activities.

Use the search box on the website if you need help with a particular topic.

## Testing your work

Run the test for the activity you are completing:

```text
make test1    Activity 1: Hello World
make test2    Activity 2: Data Types
make test3    Activity 3: Loops
make test4    Activity 4: If...Else
make test5    Activity 5: While Loops
make test6    Activity 6: Debug Practice
```

For example:

```bash
make test3
```

The tests provide feedback from `d[o_0]b ELEC2645 Bot`. A failed test is normal while you are working. Read the feedback, update your program, and run the test again.

Run `make test` to display the list of tests, or `make clean` to remove compiled `.out` files.

## Saving your work

Commit and sync your changes regularly:

1. Open the **Source Control** tab on the left-hand side.
2. Stage your changes using the **+** button.
3. Enter a meaningful commit message, such as `Complete Activity 3`.
4. Select **Commit**.
5. Select **Sync Changes** to send your work to GitHub.

Make sure you have committed and synced your final changes before finishing the unit.

Finally, copy the URL of your repository and submit it to the Code Submission Area on the Minerva Page
